**Spec:** `docs/superpowers/specs/2026-10-01-round9-design.md`

## Global Constraints
- Service key `networking`, label `Networking`, icon `fa-network-wired`, position after `electrical`.
- Settings rows (adverts table): `__google_settings` `{ apiKey, placeId }`, `__brand_settings` `{ primary }` (hex `#RRGGBB`).
- Review rows: `data.status` ∈ `pending | published`; public submissions always `pending`.
- Text on accent: `#140c05` if contrast(accent, #140c05) ≥ contrast(accent, #fff), else `#ffffff`.
- Test command: `$env:PLAYWRIGHT_BASE_URL='http://localhost:3000'; npx playwright test --workers=1`.
- Not a git repo: backups in `_backup-before-round9-2026-10-01/`; README changelog per task.

## Review Focus
1. A visitor submits a review with HTML/script in name or text → stored, shown escaped after approval, never executed.
2. Google key missing/wrong/over quota → site shows the fallback box, no console spam loop, no layout jump; admin Site health shows red with the reason.
3. Brand colour very light (e.g. `#ffff00`) or very dark (`#000080`) → buttons stay readable (dark or white text chosen).
4. Multi-select delete where one delete is refused → the others go, refused ones stay selected with a message.
5. Old saved `hailifu_branding` in the owner's browser must not override the site-wide colour.
